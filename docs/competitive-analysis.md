# Fire Loans   Competitive Analysis (AU Mortgage Broker Market)

Research date: 2026-09-07

## 1. Current fireloans.com.au   baseline audit

Live-checked via browser render:

- **Template site, not custom-built.** Classic WordPress finance-template pattern: top utility bar with 6+ crammed links, generic handshake stock photo as hero background.
- **Copy quality is a liability.** Hero literally reads "Buliding a Brightter, financial future"   a typo, live, above the fold. A whole section still has unedited template placeholder copy: *"You want to make sure you're monitoring what people are posting on social networks?"*   completely unrelated to lending.
- **Testimonials look fabricated / mismatched.** "Jennifer Smith   Codetic" (Codetic is a theme/software vendor name, not a home-loan client) and "Paul Hill   Financial Officer" read as unedited demo content, not real client stories. This actively damages trust rather than building it.
- **No real tools.** "Calculate your loan" is a label, not a working calculator. No borrowing-power, repayment, or stamp-duty calculators.
- **Generic, not niche-differentiated.** Progress bars for "Digital Strategy 80%" and "Business Service 90%" belong to a generic agency template, not a mortgage broker.
- **No clear persona journeys.** Services are a flat grid (Owner Occupied, Investment, SMSF, Trust, Company, Car, Business, Construction, Commercial, Equipment) with no guided path for "first home buyer" vs "refinancer" vs "investor" vs "self-employed."
- **Verdict:** the site actively undersells a real business. Rebuilding it is close to a zero-risk decision   almost anything coherent beats the current baseline.

## 3. Patterns that separate #1-tier sites from template sites

1. **Navigate by intent, not by org chart.** Winners group nav around *what the visitor is trying to do* (buy / refinance / invest / self-employed) rather than a flat list of loan product names.
2. **Persona-first storytelling.** First-home buyer, refinancer, investor, and self-employed visitors each need to see themselves in a distinct path within 5 seconds of landing.
3. **Real, working calculators are conversion tools, not decoration**   borrowing power, repayments, stamp duty, extra-repayments, refinance-savings. Every leader has 3–6 of these; Fire Loans currently has zero functioning ones.
4. **Quantified trust beats adjectives.** "$704m saved," "5,000+ 5-star reviews," "81% of home loans settled via brokers" (MFAA, 2026) land harder than "fast, reliable, trusted."
5. **Short forms win.** 5–7 field pre-qualification forms consistently outperform long forms; mobile-first is non-negotiable (60%+ of research happens on phone).
6. **Genuine social proof, sourced and attributable.** Real client first name + suburb/loan type + outcome (e.g. "Helped Priya, a nurse in Parramatta, refinance and save $410/month") reads as true. Generic corporate-sounding names attached to vague praise reads as fake   which is exactly the current site's biggest credibility leak.
7. **Trust/compliance visibility.** Australian Credit Licence number, MFAA/FBAA membership, privacy handling   displayed, not buried.

## 4. Direct implication for the Fire Loans rebuild

- Replace flat product grid with **persona-first journeys**: First Home Buyer, Refinancing, Investor, Self-Employed, Business/Commercial, Construction   each with its own landing path, not just a "Read More" stub.
- Ship **real, functioning calculators** (borrowing power, repayments, stamp duty, refinance savings) as the anchor conversion tool, not a placeholder link.
- **Do not fabricate client testimonials or metrics**   the current site's fake-looking reviews are a measurable trust liability; see the content-sourcing note in `site-plan.md`.
- Lead with **quantified, verifiable trust markers** (years operating, ACL number, loans settled, lender panel size) rather than generic adjectives.
- Fix the fundamentals the incumbent fails at: no typos, no leftover template copy, no irrelevant sections.
